# Entregas de MobHector

- En cada cambio entregado, generar el ZIP completo con `python tools/build_release.py` y comprobar que termina correctamente.
- Entregar el ZIP al usuario junto con los cambios; conservar el flujo automático de package de GitHub Actions.
- Leer la versión de `VERSION.txt`; mantener sincronizadas las referencias de versión al crear una nueva versión de la aplicación.
- No incluir credenciales, sesiones personales, claves privadas, transcripciones ni capturas corporativas en paquetes o commits.
- Indicar si la ejecución de GitHub Actions está pendiente o falla; no presentar pruebas locales como resultados de Windows o CI.
